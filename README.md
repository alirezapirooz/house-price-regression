🏠 House Price Prediction

A simple machine learning project to predict house prices based on real estate data.

---

📊 Dataset Features

- 📐 Area
- 🛏 Room
- 🚗 Parking
- 📦 Warehouse
- 🛗 Elevator
- 💰 Price

---

🧹 Data Preprocessing

- Handling missing values
- Converting data types
- Removing outliers (Area filtering)

---

🤖 Model

- Linear Regression (baseline model)

---

📈 Workflow

- Data Cleaning 🧹
- Feature Selection 🎯
- Model Training 🧠
- Evaluation 📊

---

🔮 Output

Predicts house price based on input features.

---

⚙️ Tech Stack

- Python 🐍
- Pandas 📊
- Scikit-learn 🤖
